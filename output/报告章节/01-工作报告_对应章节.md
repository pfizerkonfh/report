## 一、项目概述

### 4、主要研究内容（补充）

在原有研究内容框架下，与技术报告第三章、第四章对应的两项研究内容及其分工如下：

**（3）空地协同三维建图与多路径规划。** 面向变电站障碍密集、空间受限、设备分布不均的作业环境，研究空中全局稠密建图与地面局部精细建图的融合方法。空中无人机以视觉、LiDAR、IMU 与 RTK 构建大范围三维点云与 3DGS 重建结果，地面机器狗以 2D LiDAR、深度相机、IMU 与编码器补充低矮区域、设备底部与遮挡区域的局部地图；通过外参标定与时间同步实现多源数据对齐，经 ICP 与 NDT 配准及 OctoMap 体素化生成分层增量式共享地图。在此基础上研究面向任务点集的全局路径规划（K-Means 分区、TSP 排序与改进 `A*`）、局部动态避障与路径重构（DWA 与 TEB），并融合红外、声学、振动等信息对变压器热点、电缆井高落差区等作语义化风险标注，供路径算法避让或提前降速。最终形成由共享地图、协同路径、自主导航与反馈重构构成的作业闭环。

**（4）多智能体任务分配与边缘智能决策系统。** 面向无人机与机器狗在作业能力、航程、续航、感知能力上的差异，研究任务解耦、平台分配、路径配合与优先级调度机制。系统把物理执行体归属（UAV、DOG 与 SHARED 三类平台）与计算落点（edge 与 cloud 两个层级）建模为两个正交维度，由规划器把长程目标分解为带依赖、带成功判据、带平台标签的子任务 DAG；由工具语义契约（Precondition、Effect、Rollback 与 RouteHint）把任务与能力的匹配转化为可判定的硬约束；由路由器结合时延预算、隐私等级、算力需求与链路状态完成端边云选路与失败回退；由 ReAct 逐步执行、有上限的重规划与 Reflexion 经验回流实现可恢复的长程任务；最后由统一评测体系输出规划成功率、动作合理度、时延分位数与失败层级归因。同步研究执行通道抽象层，使算法层与具体硬件解耦，为后续真机接入保留可替换接口。

两项研究内容的关系是：（3）产出可计算的空间与路径，是（4）任务分配与前置校验的事实来源；（4）产出动作的执行主体、执行时序与计算层级，是（3）地图与路径真正被使用的出口。二者共同支撑项目感知、理解、决策与执行闭环。

按需求规格说明书 1.2 节，项目目标共 11 项，与上述两项研究内容直接相关的是第（1）项多模态空地感知平台与协同控制系统、第（3）项空地协同三维建图与多路径规划、第（4）项多智能体任务分配与边缘智能决策系统，以及第（8）项变电设备智能巡检系统集成。说明书第（11）条同时明确，科技项目主要侧重完整度和工作量，允许存在技术探索和技术不成熟；据此本稿对已完成实现与尚在设计阶段的算法路线分别标注，不以后者充当验收结论。

### 5、技术方案、方法和技术路线（补充）

本项目总体采用空地协同感知 + 分层建图融合 + 语义路径规划 + 多智能体协同调度 + 边云协同决策的技术路线。与上述两项研究内容对应的主线如图 W-1 所示。

```mermaid

    A["空地协同感知"] --> B["分层建图与融合"]
    B --> C["语义路径规划"]
    C --> D["多智能体任务分配"]
    D --> E["端边云执行与反馈"]
    E --> F["统一评测与验证"]
```

**图 W-1 研究内容（3）（4）总体技术路线**方法要点如下：

1. **建图与规划方法**：以 3DGS 重建产物与激光点云为真实数据源，统一 X-Z 水平、Y 竖直坐标系，按 0.2 m 分辨率生成三值占据栅格（自由、障碍与未知）；全局以任务点集分区排序后逐段寻路，局部以动态窗口与弹性带方法跟踪与避障，语义风险以加权代价参与路径评价。

   空中稠密重建环节另开展了**少视角快速重建技术攻关**：针对一次架次可用视角少、机载算力与作业窗口有限的条件，采用显式高斯基元表达，在训练侧引入按球谐阶数递增的系数正则与重要性感知的不透明度随机失活以抑制过拟合，在密度控制侧以多视图一致性误差统计引导基元复制/分裂与预算化剪枝，在渲染侧以紧凑包围盒裁剪瓦片、统计通道下沉到定制光栅化内核压缩单次迭代开销，并把总迭代预算压缩到 1 万次、高阶外观参数降频更新。该部分属算法实现与参数配置层面的工作，重建墙钟耗时与显存峰值尚未在变电站现场实测，现场验证数据待多场景试验补齐（技术细节见技术报告 3.5 节）。
2. **调度与决策方法**：以任务—能力匹配为硬约束，以完成时间、负载均衡、能耗与优先级为优化目标；工程实现采用大模型分解 + 规则化结构校验 + 前置条件硬校验，配合端边云路由判定树与有界重规划，保证分配结果可判定、可回放、可恢复。
3. **验证方法**：软件正确性采用自动化回归测试、真实重建数据计算与真实大模型端到端跑测；功能符合性委托第三方按 GB/T 25000.51—2016 测评；装置性能与环境适应性委托第三方按 GB/T 6587—2012 与测试大纲检测；现场应用按任务书要求在 220 kV 变电站开展验证并形成应用报告。
4. **工程化方法**：以 ToolSpec 语义契约与 ToolAdapter 执行通道解耦算法层与硬件层，提供 legacy、sim、playback、ros2 与 zsibot 五类通道，支持从离线回归、硬件在环仿真、录播回放平滑过渡到真机接入；全链路以 SSE 事件流与统一评测记录保证可观测、可归因。

**第四阶段（2026 年 10 月中旬，系统集成与测试）**：完成全系统集成与联调、实验室环境下的全功能测试（感知、建图精度、路径规划效率、缺陷识别准确率、系统稳定性），并与松江公司协调确定现场测试时间，具备现场测试就绪条件。

**第五阶段（2026 年 11 月—12 月，现场部署与成果验收）**：在变电站完成系统部署与性能测试，采集长期运行数据并迭代优化软件、模型与系统；完成研究报告、应用报告、专利申请与软著登记，完成项目验收准备。关键里程碑为现场应用验证通过、全部交付成果完成。**现场应用的具体站点、日期与结论，以最终现场记录和应用报告为准填入。**

工作思路上坚持三条原则：一是**先统一事实再谈智能**，先把坐标系、地图语义、时间同步与工具契约固化，再引入大模型做分解与决策；二是**先仿真后真机**，用硬件在环仿真暴露时序、超时、急停、Effect 回写等模块边界缺陷，避免把风险留到现场；三是**证据分级**，第三方检测、软件实测、仿真推演分别标注，不把推演数字当作性能结论。

### 4、项目风险控制过程（补充）

本项目执行周期内严格履行合同规定，商务部分合规，技术部分完成研究内容与合同约定要求，未存在重大风险问题。针对两项研究内容识别的技术风险及控制措施如下：

| 风险 | 表现 | 控制措施 | 处置结果 |
| --- | --- | --- | --- |
| 空地地图配准失败 | 视角与尺度差异导致地图错位 | 统一坐标系 + 外参标定 + ICP/NDT + 同名点校验 | 建图精度第三方检测 0.47 cm（要求 ≤5 cm） |
| 路径不可达与未知区误判 | 目标点落在障碍或未知格 | 三值占据语义、最近可通行格纠偏、途经未知区占比显式输出 | 真实栅格上 `A*` 得到 58 格（11.73 m），与原导航管线一致 |
| 长程任务跑偏或工具误调用 | 大模型在条件不满足时仍调用工具 | Precondition/Effect 硬校验 + GoalRegistry 对齐 + 有界重规划 | 真实端到端跑测前置违例 0 次、动作合理度 1.00 |
| 链路抖动 / 云端不可用 | 任务下发超时、决策中断 | 端边云判定树 + 降级回退 + 指数退避 + 保持上一可信状态 | 第三方测评任务下发 ≤1 s、控制指令 10 次 100% 成功 |
| 急停后仍自主行动 | 安全事故风险 | CancellationToken + cancelled 终止分支 | 软件停机响应由约 95 s 降至 6.7 s（软件响应实测，非真机停机） |
| 仿真数据被误当作实测 | 对外材料口径失真 | 每项量化结论标注实测/推演/占位，第三方结论单独引用 | 技术报告只述方法，量化结论与证据分级由工作报告统一列示 |
| 真机接入坐标未标定 | 航点整体偏移 | 不少于 2 组同名点标定，未标定禁止下发，默认 dry_run | 虚拟狗联调台完成全链路验证，真机下发须分级试车 |

## 四、项目创新点和取得的突破（补充）

1. **分层增量式共享地图构建。** 针对空地平台视角、尺度、传感器配置差异大导致的地图不一致与信息孤岛问题，提出几何层 / 占据层 / 语义层分层组织、按变化块增量同步的共享地图机制，空中平台无需持续回传全量点云，地面平台不必等待全局重建即可开展局部作业。已形成发明专利申请《分层增量式共享地图构建方法与系统、电子设备及介质》（申请号 202611417862.3）。

2. **语义风险驱动的三维地图路径规划。** 在传统几何最短路之外引入红外热点、声学异常、高落差区等语义标注，以加权代价函数参与路径评价，使高风险区避让、高落差区降速成为可被路径算法直接消费的约束，而非人工经验。已形成发明专利申请《基于三维语义地图的变电站智能巡检路径规划方法和系统》（申请号 202611472329.7）。

3. **狗载起降与能源管控的空地路径接续。** 以机器狗作为无人机移动起降与补能平台，把续航短、机巢成本高与地面视角受限两个问题合并求解，形成路径接续与多点起降机制。相关成果形成发明专利申请《电力巡检四足机器人无人机起降平台及控制方法》（申请号 202611583236.1）与《变电站空地协同巡检系统能源管控方法、系统、介质、终端》（申请号 202611593739.7）。

4. **物理平台与计算层级双维度正交分配。** 把 Platform（UAV、DOG 与 SHARED）与 RouteTier（edge 与 cloud）拆成两个独立维度，每个子任务与每个执行步同时携带两类标签，解决无人机做什么、机器狗做什么、在哪一层算力上做被混为一谈的问题；真实大模型跑测中能把航拍绝缘子分配至 UAV、把巡查开关柜分配至 DOG。

5. **可判定的工具语义契约与可恢复长程执行。** 用 Precondition、Effect、Rollback 与 RouteHint 把工具能力与执行后果显式化，执行前硬校验、偏离全局目标即拦截；配合 GoalRegistry、有上限的重规划与 Reflexion 经验回流，使长链条任务失败可解释、可收敛。真实端到端巡检中前置校验违例 0 次、动作合理度 1.00。

6. **语义契约与执行通道解耦的可替换架构。** ToolSpec 描述做什么，ToolAdapter 描述执行实现，提供 legacy、sim、playback、ros2 与 zsibot 五类通道；换真机只换适配器，规划、推理、路由与评测均无需修改。硬件在环仿真由此暴露并修复了超时预算、语义 Effect 回写、急停终止、纯计算工具结果被覆盖等 7 类模块边界缺陷，其中急停后仍继续重规划由约 95 s 降至 6.7 s 软件响应。

7. **统一评测与跨层归因体系。** 以 task + trace_id 贯穿规划、动作、推理、网络与交互层，输出规划成功率、动作合理度、p50/p95/p99、端到端时延与失败层级归因，并提供离线回放与 A/B 护栏，使调度策略优化有可比较、可回滚的基线。

8. **面向少视角巡检影像的快速三维重建方法。** 把可用视角少与要求出图快这一对矛盾拆解为三条并行路径：以按阶数递增的球谐系数正则（含保留概率无偏补偿）抑制高频伪纹理，以重要性感知的不透明度随机失活抑制新视角漂浮物，以至少两个视角共同欠拟合作为增密门槛抑制无效增生；再以紧凑包围盒裁剪瓦片、把误差统计下沉到光栅化内核、分离式优化器与 1 万次迭代预算压缩单次训练成本。该成果为方法实现与工程配置层面，现场消融与墙钟耗时实测待补，口径见技术报告 3.5 节。

## 七、项目取得的成效及后续展望（补充）

### （一）已取得的成效

1. **合同量化要求达成**：合同技术条件经第三方检测判定满足，其中空地协同建图精度 0.47 cm（要求 ≤5 cm）、时间同步 ≤1 ms、局部建图刷新率 ≥10 Hz、调度响应 ≤1 s；软件功能性测评 4 个测试项全部符合，覆盖多模态空地感知平台与协同控制、空地协同三维建图与多层次路径规划、多智能体任务分配与边缘智能决策、多模态缺陷识别与设备健康评估。
2. **系统能力**：形成由空地异构采集、分层共享地图、多层次路径规划、多智能体任务分配、端边云执行与统一评测构成的完整软件链路；原型系统 95 项自动化测试全部通过，真实大模型端到端巡检 6 步全部完成并自主调用真实感知工具；在真实 3DGS 栅格上规划出 58 格 / 11.73 m 路径，与原始导航管线结果一致。
3. **知识产权与文档**：4 项发明专利申请、2 项软件著作权登记获受理；取得装置检测报告 W02605200142、软件测评报告 W02605730012；形成技术报告、用户使用手册与测试记录等文档体系。
4. **方法价值**：建立实测 / 推演 / 占位分级标注的证据纪律，在不具备真机实测条件的研究阶段，仍能清晰界定结论的适用范围，避免把仿真数字当作性能论证。

### （二）存在的不足

原型系统的执行通道仍以离线 Mock、硬件在环仿真与录播回放为主，尚未完成真实机器人硬件的端到端实测；电量、里程、架次耗时与端侧 VLA 时延均为模型推演；Reasoner 当前按 ready_nodes()[0] 串行执行，未发挥无人机与机器狗可并行的物理条件；感知数据仅覆盖单一实验室场景，语义风险标注尚未与真实缺陷识别模型联动；安全联锁、持久化、鉴权审计等工程化能力仍待建设。

### （三）后续展望

1. **接单台真机**：优先机器狗，以 zsibot / ros2 通道替换仿真通道，完成坐标标定、分级试车与真实时序、能耗标定，把链路上的推演值替换为实测值。
2. **空地并行协同**：把串行执行改为按平台分组并发调度，加入时空冲突消解与时间窗对齐，发挥空地并行的效率优势。
3. **真实端侧智能**：接入 3B 级 VLA 模型与 INT4 量化推理，替换连乘系数时延公式，实测端侧时延分布与 p99。
4. **多场景现场验证**：在 220 kV 及以上无人值守变电站开展多天气、多光照、多任务密度验证，补充建图精度、巡检点到达率与调度响应时间的现场统计，形成可复制、可推广的技术方案。
5. **工程化与标准化**：推进安全联锁硬件化、数据持久化、鉴权审计与模型服务直连，沉淀空地协同巡检的数据接口、通信协议与测试规范，支撑成果向配电房、输电线路、新能源场站等场景推广。
