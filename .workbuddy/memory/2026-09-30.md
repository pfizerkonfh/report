## 多智能体任务分配与边缘智能决策系统 总体设计（项目核心第4目标）
- 依据 `项目背景.docx`（国网变电站空地协同无人巡检科技项目，11项目标）完成系统设计文档，重点解决四个关键问题：
  1. **Agent 长程规划失败**：引入 Goal Registry + World State；工具描述规范加 Precondition/Effect/Rollback；Planner(长程DAG,不调工具)/Reasoner(逐步,校验前置) 分层；Reasoner 用 ReAct 循环，失败用 Reflexion 写 self-critique 进 Experience Buffer 持续优化。
  2. **端侧 VLA 延迟(3B INT4, 65ms, 20Hz)**：结构层 MoE 稀疏 + 知识蒸馏；量化层 AWQ(INT4)+SmoothQuant(W8A8)；算子层 FlashAttention + PagedAttention；统一 latency harness(p50/p95/p99 + 控制环频率)，目标 p99<50ms。
  3. **端-边-云路由协议**：RouteDecision 字段 + 判定树(隐私→时延预算→算力强度)；边侧=实时/隐私/轻量，云端=重算力/大模型；回退=边→云升级、云→边降级；抖动治理 stale-state hold/自适应频率/退避+抖动/QUIC。
  4. **统一评测体系**：以 task+trace_id 贯通三层；指标=规划成功率/动作合理度/端到端时延/用户满意度；跨层归因矩阵定位根因层；离线回放 + 在线 A/B + 护栏自动回滚闭环。
