# 2026-09-27

## 3DGS 建图结果可视化展示（exp/ 目录）
- 输入：标准 Inria 3D Gaussian Splatting 输出（point_cloud.ply、train/test 的 renders+gt、cameras.json、metrics）。
- 关键数据：iter10000 模型 387,299 个高斯（96MB，sh_degree=3）；测试集 13 视角、训练集 85 视角；98 个相机位姿。
- 量化：测试集均值 PSNR 28.06 dB，训练集采样均值 33.40 dB（用 Pillow+numpy 计算）。
- 交付物：`exp/viewer/index.html`（自包含展示页）：
  - 可交互 3DGS 查看器（three + @mkkellogg/gaussian-splats-3d，已 vendored 到 vendor/，importmap 映射 three）。
  - 渲染 vs 真值 before/after 拖动对比画廊（gallery.json）。
  - PSNR 指标面板（metrics.json）。
- 运行方式：在 `exp/` 起 http.server（如 8753），浏览器开 `/viewer/index.html`。PLY 必须经 HTTP 加载（不能用 file://）。
- 坑：mkkellogg 模块内部 `import ... from 'three'`，必须用 importmap 指向本地 three.module.js；格式传 `GS.SceneFormat.Ply`；初始机位用 cameras.json 中相机位置、lookAt 用相机质心。
- 量化脚本：`exp/viewer/compute_metrics.py`（可重跑生成 gallery.json/metrics.json）。
